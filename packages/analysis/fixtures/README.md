# Analysis fixtures

Test modules for `packages/analysis` and the golden tests that hash the `LevelData` built
from them. Every fixture here is generated by a script in this repository, so there are no
licensing questions. The bytes are committed and `*.mod` is `binary` in `.gitattributes`, so
the hashes below never change unless the generator changes. A test regenerates each file and
compares it byte for byte.

## pb-fixture-01.mod

Title "pb fixture 01". Channels use the classic L R R L layout: channel 1 (left) drums,
channel 2 (right) bass, channel 3 (right) lead, channel 4 (left) hats or pad. Samples: 1 kick,
2 snare, 3 closed hat, 4 bass (looped square), 5 lead (looped saw), 6 pad (looped triangle).

Order list (7 entries): `0 1 2 1 3 2 4`. Patterns 1 and 2 play twice. libopenmpt 0.8.10
reports a duration of 47.23 s and detects the song end at the jump back to order 2.

Rows are zero-based; order is the position in the order list.

| Pattern | Plays at order | Contents and effects |
|---|---|---|
| 0 | 0 | Intro. Kick (channel 1) and hats (channel 4), bass with arpeggio `037` or `047` on rows 0, 16, 32, 48. Speed `F06` on row 0 (channel 1), tempo `F7D` (125) on row 0 (channel 4). Set volume `C30` and `C18` on the hats. |
| 1 | 1, 3 | Verse. Kick and snare, eighth-note bass, lead melody, hats. Vibrato `446` on the lead at rows 8, 24, 40, 56. Tempo `F8C` (140) on row 32 (channel 1). |
| 2 | 2, 5 | Bridge. Sparse kick, pad on channel 4 with arpeggio on rows 0, 8, 16, 32, 48, 56. Speed `F06` and tempo `F8C` on row 0. Bass: tone portamento `310` rows 8 to 15, portamento up `106` rows 20 to 23, portamento down `206` rows 40 to 43, volume slide `A04` rows 56 to 59. Lead: vibrato `446` row 0, portamento up `106` rows 20 to 23, portamento down `205` rows 36 to 39, tone portamento `308` rows 52 to 55, volume slide `A04` rows 56 to 59, set volume `C10` row 62. |
| 3 | 4 | Breakdown. Speed `F04` on row 0, back to `F06` on row 32. Pattern loop `E60` on row 8 and `E63` on row 15 (rows 8 to 15 play three extra times). Lead arpeggio on rows 0, 16, 32, 48. Pattern break `D08` on row 47 (channel 3): the next order starts at row 8. |
| 4 | 6 | Outro. Kick, snare, bass, lead, hats on every fourth row, snare fill on rows 56 to 62. Position jump `B02` on row 63 (channel 3) back to order 2. |

Because of the pattern break, order 5 (pattern 2) starts at row 8, so its row 0 tempo and
speed commands only run in order 2 and after the loop.

How it is generated: `tools/make-fixture-mod.ts` exports `makeFixtureMod()`. Samples come
from triangle waves, a 16-bit LFSR (linear feedback shift register) for noise, and integer
envelopes. `packages/analysis/test/fixture-mod.test.ts` checks that the committed file equals
the generator's output.
